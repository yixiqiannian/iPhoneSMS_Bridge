# MessageAlert 使用说明

**一句话：iPhone 收到的短信，会实时弹到 Windows 电脑右下角。**

手机放一边充电，验证码、快递通知、银行动账短信一到，电脑立刻弹窗提醒——不用再拿起手机看。

---

## 一、它能做什么

- ✅ 短信一到，电脑右下角立刻弹出通知（中文正常显示，带提示音）
- ✅ 完全在你自己家里运行：手机和电脑同一个 Wi-Fi 就行，消息不经过任何互联网服务器
- ✅ 界面上一眼看到访问地址，点一下就复制，填进 iPhone 快捷指令
- ✅ 不只能推短信：任何能发网页请求的设备/程序都能往电脑推消息
- ✅ 关掉窗口就退出，不占后台、不装服务、不改系统设置

---

## 二、怎么启动（就一步）

**双击 `run.bat`。**

首次运行会自动装好需要的组件（需要联网，大约 1~2 分钟，只做一次）。以后再双击，2 秒内窗口就出来了。

启动后窗口从上到下是这几块：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 标题 **MessageAlert** +「iPhone 消息，实时推送到电脑右下角」 |
| 地址卡 | **本机访问地址**，例如 `http://192.168.1.100:9527`，右边是「复制地址」按钮 |
| 使用说明 | 三步指引 + 一条 URL 示例 |
| 状态点 | **● 服务运行中**（绿色）/ 服务未连接（红色） |
| 底部 | 公众号二维码 + 「请关注公众号 Moon杂选」 |

### 第一次启动可能会弹两个系统提示

| 弹窗内容 | 怎么点 |
| --- | --- |
| **Windows 安全警报**：「是否允许 Python 访问网络」 | 勾选 **「专用网络」**，点 **「允许访问」**。不点允许，手机就连不上电脑 |
| 浏览器/杀毒软件提示"未知程序" | 允许运行即可（本软件完全本地运行，不联网上传任何数据） |

> ⚠️ **窗口不要关。** 关掉窗口 = 软件退出 = 手机推送就收不到了。想让它一直在后台，见本文「六、让它开机自动启动」。

## 三、界面上的地址，就是快捷指令要填的地址

窗口里显示的 **`http://192.168.1.100:9527`**（你电脑上会显示成你自己的 IP，比如 `http://172.20.10.8:9527`）就是 iPhone 要访问的地址。

- 点 **「复制地址」** 可以一键复制（变成「已复制 ✓」就是成功了）
- 下面的 **「服务运行中」绿点** 表示服务正常；如果变红点「服务未连接」，说明后台服务挂了，关掉窗口重新双击 run.bat
- 底部二维码是公众号，不是用来配推送的

## 四、iPhone 快捷指令配置（重点，照着做就能通）

目标：**iPhone 一收到短信 → 自动把短信内容发到你电脑 → 电脑弹窗。**

全程在 iPhone 上操作，大约 3 分钟。

### 第 1 步：打开「快捷指令」App

在 iPhone 上找到自带的 **「快捷指令」** App（图标是彩色方块拼成的图案）。
如果找不到，去 App Store 搜「快捷指令 / Shortcuts」免费下载。

### 第 2 步：进入「自动化」新建

1. 点屏幕**底部**的 **「自动化」** 标签
2. 点**右上角的 `+`**
3. 选 **「创建个人自动化」**

### 第 3 步：选触发条件「信息」

在列表里找到并点击 **「信息」**（Message）。

然后设置触发规则，二选一（也可以两个都设，更精准）：

| 想推什么短信 | 怎么设 |
| --- | --- |
| **所有短信都推** | 「发件人」和「信息包含」都留空，直接下一步 |
| **只推验证码** | 点「信息包含」→ 输入 `验证码`（部分短信写作「校验码」「动态码」，可只填 `码`） |
| **只推某个号码的短信** | 点「发件人」→ 输入号码或联系人 |

设好点右上角 **「下一步」**。

### 第 4 步：添加操作「获取 URL 内容」

1. 点 **「添加操作」**
2. 在搜索框输入 **`获取 URL 内容`**（英文版是 *Get Contents of URL*），点它添加进来

### 第 5 步：填 URL（关键）

在刚添加的操作里，点 **「URL」** 右边的输入框，输入：

```
http://192.168.1.100:9527/push?title=短信&content=
```

> 把 `192.168.1.100` 换成**你电脑窗口上显示的那个 IP**。
> 注意：`/push?title=短信&content=` 这一串要**一字不差**（都是英文标点）。

然后，**光标停在 `content=` 后面**，点键盘上方/输入框右侧的 **「选择变量」**（一个蓝色 `+变量` 或 `x` 图标）：

1. 在弹出的变量列表里，找到 **「快捷指令输入」**（Shortcut Input）
2. 点它插入

插好后输入框长这样（`content=` 后面多了一个蓝色的变量胶囊）：

```
http://192.168.1.100:9527/push?title=短信&content= [快捷指令输入]
```

> 💡 **快捷指令输入 = 这条短信的正文。** 短信自动化触发时，短信内容就是这个「输入」。

### 第 6 步：方法保持 GET（默认就是）

点操作里的 **「方法」**，确认是 **`GET`**。
再点 **「显示更多」/「高级」**，确认「请求头」「请求体」都是空的（**不要**填任何东西）。

### 第 7 步：关掉「运行前询问」（必须！）

点右上角 **「下一步」**，进到最后一页：

- **「运行前询问」** → 关闭（滑块变灰）。会弹窗问一次，选 **「不询问」**
- **「运行时通知」** → 关闭

这一步不做的后果：每来一条短信，手机都先弹一个"是否运行"，你还得手动点一下——等于白配。

### 第 8 步：完成，测试

点右上角 **「完成」**。

测试方法（两种都行）：

**方法 A（推荐，最快）**：用另一台手机给自己的 iPhone 发条短信，看电脑右下角有没有弹窗。

**方法 B**：先在电脑上验证电脑这端是通的——把下面地址贴进电脑浏览器地址栏回车：

```
http://127.0.0.1:9527/push?title=测试&content=中文测试成功
```

电脑右下角应该立刻弹出「测试 / 中文测试成功」。如果电脑这端没问题，那就只剩手机到电脑这一段了（看第五节 FAQ）。

### 进阶：正文含特殊符号时改用 POST

如果短信内容里有 `&`、`#`、`+` 等字符，或者推送的长文本被截断，可以把方法从 `GET` 改成 `POST`，更稳：

| 项目 | 填什么 |
| --- | --- |
| 方法 | `POST` |
| URL | `http://192.168.1.100:9527/push` |
| 请求头 | 新增一组：键 `Content-Type`，值 `application/json` |
| 请求体 | 选 `JSON`，加两个文本字段：`title` = `短信`，`content` = 变量「快捷指令输入」 |

## 五、常见问题（FAQ）

### Q1. 短信收到了，电脑没弹窗

按顺序排查：

1. **电脑窗口还开着吗？** 关了窗口服务就停了。
2. **绿色「服务运行中」还在吗？** 红了就重启 run.bat。
3. **手机能连上电脑吗？** 用 iPhone 的 Safari 打开 `http://<电脑IP>:9527/`，能看到和电脑一样的界面就说明网络通。
4. **电脑的通知被关了吗？** 打开 设置 → 系统 → 通知，确认「通知」总开关是开的，并允许「MessageAlert」发通知。
5. **开了勿扰/专注助手吗？** 任务栏右下角若有月亮图标，点一下关掉；通知会被静音但不会丢失，可在通知中心看到。
6. **快捷指令的「运行前询问」关了吗？** 没关的话每次都要你手动点，看起来就像"没反应"。回去把第 7 步补上。

### Q2. 手机打不开 `http://电脑IP:9527/`（一直转圈/无法访问）

按顺序检查：

1. **手机和电脑连的是同一个 Wi-Fi 吗？** 这是最常见的原因。手机用 4G/5G、或连了另一个 Wi-Fi（比如连了 5G 频段而电脑连 2.4G，通常仍算同一网络，但如果路由器开了「AP 隔离」就会不通）。
2. **IP 填对了？** 打开电脑窗口核对，别把 `0` 看成 `O`。
3. **路由器开了「AP 隔离 / 访客网络」？** 访客 Wi-Fi 一般禁止设备互访，换成主 Wi-Fi。
4. **Windows 防火墙拦了 9527 端口。** 见 Q3。
5. **电脑 IP 变了？** 重启路由器后 IP 可能变化，看窗口重新复制新地址。

### Q3. 怎么放行 Windows 防火墙的 9527 端口

**方法一（图形，简单）**：首次启动时弹的「Windows 安全警报」里勾选「专用网络」并允许，就已经放行了。错过了就：

1. 打开 设置 → 网络和 Internet → 防火墙 → **「允许应用通过防火墙」**
2. 找到 `Python` / `pythonw`，勾上「专用」
3. 没有的话点「更改设置」→「允许其他应用」→ 浏览到 `F:\messagealert\venv\Scripts\pythonw.exe` 添加

**方法二（命令行，最直接）**：在开始菜单搜 `cmd` → 右键「以管理员身份运行」，粘贴：

```bat
netsh advfirewall firewall add rule name="MessageAlert 9527" dir=in action=allow protocol=TCP localport=9527
```

输完回车，出现「确定」就好了。

### Q4. 电脑锁屏/睡眠后收不到

电脑睡眠或关机时，任何服务都停着，短信当然收不到。想尽量不收漏：

- 设置 → 系统 → 电源 →「屏幕和睡眠」把「接通电源时让设备进入睡眠状态」改成 **「从不」**
- 屏幕可以关，**睡眠不要开**

笔记本合盖也可能睡眠：控制面板 → 电源选项 →「选择关闭盖子的功能」→ 接通电源时选「不采取任何操作」。

### Q5. 提示 9527 端口被占用 / 双击后没反应

多半是上一次没关干净，或者别的程序占了端口。打开 `cmd` 执行：

```bat
netstat -ano | findstr :9527
```

最后一列是进程号（PID），然后：

```bat
taskkill /PID 上面查到的PID /F
```

如果嫌麻烦：**直接重启电脑最快。**

### Q6. 双击 run.bat 闪一下就没了

用记事本打开同目录的 **`app.log`**，最后几行会写明原因（这是程序自己记的日志）。常见原因：

- 没装 Python 3 → 到 <https://www.python.org/downloads/> 安装，**安装时务必勾选 "Add python.exe to PATH"**
- 杀毒软件拦截了 `pythonw.exe` → 加白名单
- 依赖没装全 → 删掉 `venv` 文件夹，重新双击 run.bat 让它重装

### Q7. 每次重启电脑，地址里的 IP 都变了

正常现象——路由器动态分配 IP。有两招：

1. 每次启动看窗口显示的新地址，在快捷指令里改一下（30 秒）
2. 进路由器后台把电脑 MAC 地址绑定成固定 IP（一劳永逸，需登录路由器）

### Q8. 想用别的设备推消息（不止 iPhone）

任何能发 HTTP 请求的东西都行，接口很简单：

```bash
# GET（浏览器直接访问也行）
http://192.168.1.100:9527/push?title=标题&content=内容

# POST JSON
curl -X POST http://192.168.1.100:9527/push ^
  -H "Content-Type: application/json" ^
  -d "{\"title\":\"服务器告警\",\"content\":\"磁盘使用率 92%\"}"
```

返回 `{"ok": true}` 即表示已推送到电脑并弹窗。

> 小提示：中文 Windows 的 cmd / git-bash 里，命令行参数里的中文会变成本地代码页（GBK）
> 字节发出去，本程序已自动识别（UTF-8 / GBK 都能推成功）；若确实解析不出来，
> 返回的错误会明确提示「请求体解析失败，请用 UTF-8 编码提交」。

## 六、让它开机自动启动（可选）

如果你希望开机就有、不用每次双击：

1. 右键 `run.bat` → **「发送到」→「桌面快捷方式」**
2. 按 `Win + R`，输入 `shell:startup`，回车（会打开「启动」文件夹）
3. 把桌面刚生成的那个快捷方式**剪切**，粘贴进「启动」文件夹
4. 下次开机，程序会自动启动并弹出窗口

> 如果哪天不想自启了，回到这个「启动」文件夹把快捷方式删掉即可。
> 注意：自动启动后窗口会占据屏幕一小块，用完关掉窗口 = 退出程序。

## 七、文件都是干什么的 / 怎么卸载

| 文件 | 作用 |
| --- | --- |
| `run.bat` | **双击这个启动**（首次自动装依赖） |
| `app.py` | 主程序：开窗口 + 启动后台服务 |
| `server.py` | 后端接口（接收手机推送、查本机 IP、控制界面；也可单独 `python server.py` 直接跑） |
| `notify.py` | 负责弹 Windows 右下角通知 |
| `templates/index.html` | 窗口里看到的界面 |
| `static/qrcode.jpg` | 界面上的公众号二维码 |
| `venv\` | 运行环境（首次运行时自动生成，几百 MB） |
| `app.log` | 运行日志，出问题时看这里 |

**卸载**：先关掉窗口，然后直接删除整个 `messagealert` 文件夹即可。不写注册表、不装系统服务、不留残留。
